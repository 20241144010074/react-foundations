# Capítulo 2 - Renderizando Interfaces de Usuário

## Rendering User Interfaces (UI)

Neste capítulo foram estudados os fundamentos de como uma interface de usuário é renderizada no navegador.

### HTML

HTML é utilizado para estruturar os elementos de uma página web, como títulos, parágrafos, imagens e botões.

### DOM

DOM significa Document Object Model. Ele representa a estrutura de um documento HTML como uma árvore de objetos que pode ser acessada e modificada por JavaScript.

### Renderização

O navegador recebe o código HTML, interpreta sua estrutura e cria o DOM. A partir dessa estrutura, os elementos da interface são apresentados ao usuário.

### JavaScript e DOM

JavaScript pode acessar e modificar o DOM, permitindo atualizar elementos da interface de usuário de forma dinâmica.

### React

React utiliza esses conceitos para facilitar a criação e atualização de interfaces de usuário.

## Conclusão

O capítulo apresentou a relação entre HTML, DOM, JavaScript e a interface de usuário, preparando o estudo para a atualização da UI com JavaScript nos próximos capítulos.
